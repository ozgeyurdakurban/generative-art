# Hafızanın Çoğalan Çevresi / Memory’s Multiplying Circumference

[Projenin ayrıntılı hikâyesi / Full project story](../../README.md) · [Code](sketch.js) · [Run](index.html)

## Türkçe

Yıldız, pıtrak ve göz birer halka boyunca çoğalır. Karşı yönlerde dönmeleri, aynı merkezin tek bir bakışa kapanmamasını sağlar. Psikedelik etki motiflerin üzerinde bir örtü gibi durmak yerine, motifin kendi tekrarından doğar. Koyu zemin ve parlak kontur yankıları algısal derinliği artırır. Üç halka kökte yoğunlaşır, göçte yatay bir yol duygusuna açılır; evre yazıları bu sürümde hâlâ görünürdür.

Motiflerin kaynak anlamları, renk ve yöre araştırmasının sınırları, ana proje README dosyasında açıklanır. Bu sürüm aynı 90 saniyelik kök–göç–kök düşüncesinin ayrı bir aşamasıdır.

## English

Stars, burdock forms and eyes multiply around three rings. Counter-rotation prevents the shared center from settling into a single view. Psychedelia grows from the motif’s repetition rather than covering it with unrelated decoration. A dark ground and brighter contour echoes deepen perception. Rings gather in rootedness and flatten toward a route in migration; phase labels are still present.

The main project README explains the motifs’ reference meanings and the limits of the color and regional research. This version is a distinct stage of the same ninety-second root–migration–root concept.

## Çalıştırma / Running

Open index.html with internet access for p5.js. Space pauses/resumes; R restarts; S saves a PNG. This archived version has no video-export controls.
