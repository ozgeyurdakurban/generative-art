# Döngünün Taşınabilir İzi / A Portable Trace of the Cycle

[Projenin ayrıntılı hikâyesi / Full project story](../../README.md) · [Code](sketch.js) · [Run](index.html)

## Türkçe

Görsel 03 ile aynıdır; bu sürüm zamanın paylaşılabilir kaydını ekler. Kilim parçasının yolculuğu artık ekrandan ayrılabilen bir video izi bırakır. Bu, yeni bir motif anlamı değil, eserin dolaşıma çıkabilme biçimidir. Arayüz tuval dışında kalır; indirilen görüntüde açıklayıcı yazı veya düğme bulunmaz. Etkileşimli eser ile kaydı aynı şey değildir: video bir kez yaşanmış geçişi saklar.

Motiflerin kaynak anlamları, renk ve yöre araştırmasının sınırları, ana proje README dosyasında açıklanır. Bu sürüm aynı 90 saniyelik kök–göç–kök düşüncesinin ayrı bir aşamasıdır.

## English

The visual code is identical to version 03; this version adds a shareable recording of its time. The kilim fragment’s journey can leave the screen as a video trace. This adds no new traditional motif meaning; it changes how the work may circulate. Controls remain outside the captured canvas. A recording is not identical to the interactive work: it preserves one passage that has occurred.

The main project README explains the motifs’ reference meanings and the limits of the color and regional research. This version is a distinct stage of the same ninety-second root–migration–root concept.

## Çalıştırma / Running

Open index.html with internet access for p5.js. Space pauses/resumes; R restarts; S saves a PNG. The video button records the canvas in real time.
