# Anlamın İlk Yerleşimi / The First Arrangement of Meaning

[Projenin ayrıntılı hikâyesi / Full project story](../../README.md) · [Code](sketch.js) · [Run](index.html)

## Türkçe

İlk sürümde hikâye henüz kendi başına konuşmayı öğrenmektedir. Bereket merkezi ortak yaşamı taşır; su yolu sürekliliği, iki kurt ağzı korunma ihtiyacını, hayat ağacı ise yeniden bağlanmayı görünür kılar. Metinler evreleri açıklar. Seyrek kompozisyonun amacı, motiflerin hangi anlatı görevine sahip olduğunu sınamaktır. Bu açıklık, daha sonra yoğunlaşacak görsel dilin iskeletidir.

Motiflerin kaynak anlamları, renk ve yöre araştırmasının sınırları, ana proje README dosyasında açıklanır. Bu sürüm aynı 90 saniyelik kök–göç–kök düşüncesinin ayrı bir aşamasıdır.

## English

The first version is still learning to speak through form. Fertility carries shared life at the center; the waterway suggests continuity, two wolf’s-mouth forms provide protective accompaniment, and the tree of life marks reconnection. Labels explain the phases. The sparse field tests each motif’s narrative role and provides the skeleton for later visual density.

The main project README explains the motifs’ reference meanings and the limits of the color and regional research. This version is a distinct stage of the same ninety-second root–migration–root concept.

## Çalıştırma / Running

Open index.html with internet access for p5.js. Space pauses/resumes; R restarts; S saves a PNG. This archived version has no video-export controls.
