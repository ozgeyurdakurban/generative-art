# Sözün Geri Çekildiği Doku / A Fabric from Which Words Recede

[Projenin ayrıntılı hikâyesi / Full project story](../../README.md) · [Code](sketch.js) · [Run](index.html)

## Türkçe

Bu sürümde açıklamalar görüntüden çekilir. Beş halka, göz zincirleri, pıtrak ve yıldız ızgarası ile iç içe yıldız koridorları alanı yoğunlaştırır. Hikâyeyi artık uzaklaşan ve yeniden toplanan geometriler taşır. Merkezdeki motifin okunacağı boşluk korunur; yoğunluğun her şeyi aynı ağırlıkta göstermemesi amaçlanır. Göz hem sözlükteki korunma yorumuyla hem çağdaş psikedelik bakışla ilişki kurar.

Motiflerin kaynak anlamları, renk ve yöre araştırmasının sınırları, ana proje README dosyasında açıklanır. Bu sürüm aynı 90 saniyelik kök–göç–kök düşüncesinin ayrı bir aşamasıdır.

## English

Explanatory words leave the image. Five rings, eye chains, a burdock-and-star grid and nested star corridors intensify the field. Geometry moving apart and gathering again must now carry the narrative. An opening protects the central motif’s legibility, so density need not give everything equal weight. The eye meets both the dictionary’s protective association and a contemporary psychedelic gaze.

The main project README explains the motifs’ reference meanings and the limits of the color and regional research. This version is a distinct stage of the same ninety-second root–migration–root concept.

## Çalıştırma / Running

Open index.html with internet access for p5.js. Space pauses/resumes; R restarts; S saves a PNG. This archived version has no video-export controls.
