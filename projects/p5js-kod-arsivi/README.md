# p5.js Etütleri / p5.js Studies

## Türkçe

Bu etütlerde şekilden anlatıya giden yolu araştırıyorum. Önce bir köşe, sonra bir beden, bir dal ve bir ağaç. Tekrar eden biçimlerin nerede bir desen, nerede bir hikâye kurmaya başladığını anlamaya çalışıyorum. Her klasörde kodun yanında bu arayışa ait bir metin var.

## English

In these studies I follow a path from shape to narrative: a vertex, a body, a branch and a tree. I am interested in the point where repeated forms begin to suggest a story. Each folder holds the code and a short account of that search.

## Kullanım / Running

Open index.html to select a sketch. Each sketch is standalone and includes its helper functions. The p5.js CDN requires internet access. Copy only one sketch.js at a time into the p5.js Web Editor. Ortak parçalar / shared helpers: ortak/.
